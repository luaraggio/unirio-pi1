# Central de Oportunidades UNIRIO

Sistema web para centralização de oportunidades acadêmicas da UNIRIO.

## Funcionalidades

- Consulta de oportunidades
- Busca por palavra-chave
- Filtro por categoria
- Perfil do aluno
- Favoritos
- Inscrição em oportunidades
- Persistência com LocalStorage
- Tema escuro

## Tecnologias

- HTML5
- CSS3
- JavaScript ES6

## Estrutura

/pages
/css
/js
/assets
/data

## Como executar

1. Baixar o projeto
2. Abrir index.html

Nenhum servidor é necessário.
